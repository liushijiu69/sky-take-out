# Day 3：公共字段填充和业务开发

## 1. 公共字段填充

在 `common` 模块中自定义注解 `@AutoFill`。

在 `server` 模块中定义切面类 `AutoFillAspect`。

编写前置通知方法，获取传入参数，使用反射为其赋值，注释掉 Service 层原有的手动赋值方法。

测试报错，发现反射中使用的是 `long`，而实际数据类中是 `Long` 包装类，修正后再次测试成功。提交并推送代码。

## 2. 新增菜品

文件上传：在阿里云 OSS 中新增 Bucket，然后将原有的 Aliyun OSS 工具类（过时代码）按照官网示例改造更新。将 `OSS_ACCESS_KEY_ID` 和 `OSS_ACCESS_KEY_SECRET` 改为从环境变量中读取而非直接硬编码（因为代码要推送到 GitHub 上，避免泄露隐私）。
